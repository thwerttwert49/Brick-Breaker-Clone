How to play the game:

in the menu, you can either choose to play or exit

The game will load a random level selection from the 2 levels when you start

there are 4 brick types:

ice brick: has random 1 to 3 health
snow brick: increases snowball size
red brick: creates red snowballs that damage the player and can be destroyed by other snowballs for points
blue brick: creates a clone snowball

3 collectibles/power ups

snowball size increase from snow brick (size slowly decreases back to normal)
damage from red snowballs
duplicate snowballs from blue brick

you have 3 health which is indicated by the cracks in the player's sprite

when you lose all health, you get a game over screen which shows points and asks if you want to retry or exit
